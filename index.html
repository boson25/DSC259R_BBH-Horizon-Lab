Recipe and Ratings: Predicting if a Recipe is Healthy

Team Members: Hangyi Zhao, Bokyoung Son, Brandon Rocchio

Project Overview

This project serves to see if we are able to utilize machine learning techniques to predict the healthiness of a recipe given some basic information about the recipe.

Research Question

Can we accurately predict whether a recipe is healthy based on different attributes such as calorie count, number of ingredients, average ratings, etc.
